# TermVela for macOS

TermVela 是 Apple 芯片 Mac 上的 SSH 终端与运维工作台。你可以管理主机、传输文件，并按需将使用数据同步到自己的 WebDAV。

[下载最新版本](https://github.com/timmyraul/TermVela-Releases/releases/latest) · [TermVela 官网](https://termvela.com/)

## 安装与更新

1. 确认 Mac 使用 Apple 芯片，系统为 macOS 15 或更高版本。
2. 在发行页的 Assets 中下载安装包 `TermVela-版本-arm64.zip`。解压后，将 TermVela 拖入「应用程序」文件夹。
3. 后续可通过「TermVela → 检查更新」查看更新说明并选择安装。早期客户端如果没有可用的「检查更新」，可退出后手动替换应用，本地资料会保留。

0.0.2 安装包采用 ad-hoc 签名，未经 Apple 公证。发行页提供对应安装包和用于更新校验的签名描述文件。
